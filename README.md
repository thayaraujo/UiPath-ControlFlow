UiPath Learning - If Statement
Exercise to study how to use the If Activity when working with sequences, how to use the Flow Decision Activity when working with Flowcharts, and the If operator in VB.

Business Scenario:
Find out if the reporting year is a leap year or not.
Logic - A year is a leap year if it meets the following conditions:
- The year is evenly divisible by four
- If the year is evenly divisible by 100, it is not a leap year unless the year is also evenly divisible by 400.
